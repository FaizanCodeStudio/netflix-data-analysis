# 🎬 Netflix Data Analysis

Exploratory data analysis of Netflix content across countries, genres, and release patterns.

## 📊 Visualizations
| Chart | Description |
|-------|-------------|
| Country Analysis | Top 10 countries, Movies vs TV Shows, Ratings |
| Genre Trends | Distribution, heatmap, share over time |
| Release Patterns | Yearly growth, monthly seasonality |
| Dashboard | Executive summary of all insights |

## 🛠 Tools Used
- Python 3
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 How to Run
pip install pandas matplotlib seaborn
python netflix_analysis.py
